### Mapping tables that do not join

In these adapters the variable-alias table and the description/unit table are keyed differently, so the physical meaning and output unit cannot be attached to the native variable automatically. ERA5 is the example: `DATA_ALIASES` lists request names (`2m_temperature`) while `GLOBAL_MAPPING` lists netCDF short names (`t2m`). Either align the keys in the adapter's mapping module, or supply `physical_meaning` and `native_unit` per variable in `registry/variables.yaml`.

- `cds.cds_single_levels`
